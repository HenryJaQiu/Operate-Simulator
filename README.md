# 游戏后台按键助手

一个用 Python + Tkinter 写的 **Windows 后台按键 / 鼠标自动化小工具**：选定目标窗口后，即使目标未激活、被最小化，或者你正在操作其它程序，也可以向它发送按键和鼠标点击。

> 这是一个随手 vibe coding 的小项目，主要用于自己部署的 **“北斗”冒险岛私服**，自娱自乐。代码以“能用、好改”为主，不追求工程化。

## 功能

- **目标窗口选择**：刷新窗口列表，或用鼠标拾取；可进一步选择子窗口（渲染 / 输入窗口）。
- **两种发送方式**：
  - 后台消息（PostMessage）：目标可最小化 / 不在前台，适合支持标准 Windows 消息的程序。
  - 前台模拟（SendInput）：目标窗口需要获得焦点，适合 DirectInput / Raw Input 类游戏；支持硬件扫描码、保持焦点、激活等待。
- **任务种类**：
  - 按键 / 组合键：点“捕获”后直接按键盘录入（支持 Alt、方向键、`ctrl+shift+a` 等）。
  - 鼠标左键 / 右键点击：坐标可手动填写，也可“拾取”。
  - 组合序列：多个键按顺序执行，可设置组内间隔（可选功能）。
- **每个任务独立配置**：间隔（秒）、次数或持续分钟数、按住秒数（长按，0 = 使用运行控制里的默认值）。
- **启用勾选**：表格“启用”列可单独勾选/取消；“全选”一键全选/全不选，只执行勾选的任务。
- **多个任务序列**：表格下方有“任务序列”页签，默认 3 个，可新建 / 改名（如“自动打怪2”）/ 删除；每个序列独立保存任务和**运行控制设置**，切换时自动带出。
- **运行模式**：
  - 并行计时：各任务按自己的间隔独立运行，任务的“次数 / 时长”生效。
  - 顺序循环：按列表顺序轮转；可用“循环次数”控制重复几轮，或用“总时长”控制持续多久；都填 0 则循环到手动停止。
- **按键最小间隔**：所有按键统一公平排队，避免同时按键互相顶掉；发送失败自动重试；每个任务第一次按键在启动第 0 秒执行。
- **暂停 / 继续**：暂停期间所有任务和计时冻结，暂停时间不计入总运行时长。
- **全局停止快捷键**：`Ctrl+Alt+Shift+Q`，游戏在前台 / 最小化时都可停止全部任务。
- **进度显示**：计划时长、预计次数、已运行、已发送、剩余时间 + 进度条；预计时间已计入按住时间与按键间隔。
- **自动保存配置**：程序同目录生成 `assistant_config.json`，保存任务序列、运行设置和目标窗口。

## 快速开始

### 方式一：免安装 exe（推荐给没有 Python 的电脑）

1. 解压 `游戏后台按键助手_免安装版.zip`，双击 `游戏后台按键助手.exe`。
2. 首次运行若 Windows SmartScreen 提示“未知发布者”，点 **更多信息 → 仍要运行**。部分杀毒软件可能对 PyInstaller 单文件产生误报，请自行判断并放行。
3. 如果目标游戏以管理员权限运行而本工具发不出输入，右键 exe → **以管理员身份运行**。

### 方式二：源码运行（需要本机 Python）

- 环境：**Windows 10 / 11**、Python 3.9+（官方安装包默认包含 tkinter；本项目只用标准库）。
- 双击 `run.bat`（无控制台窗口），或执行 `python game_assistant.py`。
- 需要管理员权限时使用 `run_admin.bat`（会弹 UAC）。

> 本项目只支持 Windows：大量使用 Win32 API（窗口枚举、PostMessage、SendInput、全局热键等）。

## 使用步骤

1. **① 目标窗口**
   - 点“刷新窗口”，选中游戏窗口；找不到时可用“鼠标拾取窗口”。
   - 后台发送无效时，在“发送目标”里换一个子窗口（渲染 / 输入窗口）再试。
2. **② 任务设置**
   - 选类型：按键 / 组合序列 / 鼠标左键 / 鼠标右键。
   - 按键任务点“捕获”，直接按下要用的键（支持 Alt、方向键、组合键）。
   - 鼠标任务填写或“拾取”坐标。
   - 设置间隔、方式（次数 / 时长分钟）、按住秒数（长按）。
   - 点“添加任务”；用“启用”列勾选本次要执行的任务，“全选”可批量切换。
3. **任务序列**
   - 表格下方页签切换不同任务序列；每个序列有自己的任务和运行设置。
   - 可新建 / 改名 / 删除；新序列会继承当前运行设置。
4. **③ 运行控制**
   - 选择并行计时或顺序循环；设置总时长、按住(ms)、后台/前台、保持焦点、先发激活、扫描码、按键间隔、循环次数。
   - 顺序循环：`循环` 填 N 则整份列表循环 N 次后结束；`总时长` 填分钟则到时结束；两者都为 0 则循环到手动停止。
   - 注意：顺序模式下单个任务的“次数 / 时长”不生效；它们用于并行模式。
5. **开始运行**
   - 运行中可“暂停 / 继续”；暂停时间不计入总时长。
   - “停止”按钮或全局快捷键 `Ctrl+Alt+Shift+Q` 可结束全部任务。
6. **日志 / 进度**
   - 日志区会记录发送失败、窗口失效、快捷键注册等信息。
   - 进度区显示计划时长、已发送次数、剩余时间。

## 配置文件

- 首次保存时会在程序同目录生成 `assistant_config.json`。
- 内容包含：目标窗口、所有任务序列（名称、任务、运行设置、启用状态等）。
- 换电脑或换目录时，把 `assistant_config.json` 和 exe 放在同一个文件夹即可带走配置。
- 升级版本会自动兼容旧配置；重要配置建议先备份。

## 已知限制

- 使用 **DirectInput / Raw Input** 的程序（部分 Unity / 虚幻 / 冒险岛类客户端）可能收不到后台消息，此时需改用“前台模拟”。
- 前台模拟同一时间只能让一个窗口获得焦点；**当前版本一个实例一次运行一个任务序列、控制一个目标窗口**。如需同时挂两个客户端，可临时运行两个实例（全局停止快捷键只会被其中一个实例注册）。多客户端并行支持在计划中。
- 若目标程序以管理员权限运行，本工具也必须以管理员权限运行（UIPI 限制）。
- 部分游戏有反作弊 / 输入保护，可能拦截模拟输入；工具无法保证一定生效。
- 若系统中文输入法处于中文状态，前台模式下字母键可能被输入法吞掉；建议切到英文或使用非字母键。
- 后台按键 / 宏可能违反游戏规则，请只在允许的环境中使用。

## 常见问题

**按键没反应？**
- 换用“前台模拟”，或改选子窗口；
- 用管理员身份运行本工具；
- 先拿记事本 / 游戏聊天框测试按键是否能送达；
- 检查任务是否勾选、当前是否在正确的任务序列页；
- 适当增大“按住(秒)”或“按键间隔”。

**技能 / buff 经常断？**
- 把“按键间隔”调到大于技能后摇 / 动画的时间；
- 适当增大按住时间（例如 0.05–0.1 秒）；
- 顺序模式下用“循环次数”或“总时长”控制结束，避免误以为任务次数生效。

**快捷键注册失败？**
- 通常说明已有另一个本工具实例在运行；关闭多余实例后重启。

**配置被覆盖？**
- 只保留一个实例运行；升级或换电脑前备份 `assistant_config.json`。

**exe 被 SmartScreen / 杀软拦截？**
- 单文件打包未做数字签名，属于常见误报；可添加信任，或直接源码运行。
